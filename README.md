# 🎓 Student Management System (Python CLI)

## 📌 Project Overview

This is a simple **Command Line Interface (CLI)** based Student Management System built using Python.
It allows users to manage student records by performing operations like adding, viewing, updating, and deleting student data.

---

## 🚀 Features

* ➕ Add a new student
* 📋 View all students
* ✏️ Update student marks
* ❌ Remove a student
* 🔁 Menu-driven program

---

## 🛠️ Concepts Used

This project covers the following Python topics:

* Variables & Data Types
* Input & Output
* String Manipulation
* Lists
* Dictionaries
* Loops (`while`, `for`)
* Conditional Statements (`if-elif-else`)
* Operators
* Functions like `append()`, `remove()`, `len()`, `enumerate()`
